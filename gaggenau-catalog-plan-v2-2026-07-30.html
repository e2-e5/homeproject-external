Фото · Стратегия
Собираем библиотеку самостоятельно
Фотографии от поставщика ждать не будем — собираем сами из двух источников, которые уже доступны.
📄 PDF-листовки товаров
Источник 1 — продуктовые фото (приоритет)
Каждый артикул Gaggenau имеет официальную PDF-листовку от BSH Group. В листовке — фото товара на нейтральном фоне, 1195×1200 пикс. Это лучший источник для карточки товара.

Пример: GO250100.pdf → фото духовки 1195×1200 px ✓
Статус: Уже работает
📖 Брендовый каталог PDF
Источник 2 — лайфстайл-фото (интерьеры)
Брошюра «Serie Minimalistic» — 13 маркетинговых фото кухонь с техникой Gaggenau, 1195×1689 пикс. Использовать для раздела бренда и страниц категорий.

Доступно: 13 изображений ✓
Статус: Уже извлечены
Процесс сбора фото — полностью автоматизирован:
1. Скрипт берёт артикул из Excel
2. Скачивает PDF-листовку по артикулу с BSH Group
3. Извлекает изображение (1195×1200 px) из страницы 1
4. Конвертирует PNG → JPEG 85%
5. Загружает на CDN сайта

Оценка: 204 артикула × ~5 сек = ~17 минут машинного времени

План действий
1
Согласовать план с поставщиком  СЕЙЧАС
Отправить этот документ Анне Даутовой (Küchengesellschaft). Получить подтверждение: структура карточек, формулировки, использование фото из PDF-листовок.
2
Собрать фото-библиотеку — 204 артикула  ~17 МИН
Автоматический скрипт: для каждого артикула скачать PDF-листовку, извлечь фото, сохранить. Результат: папка с 204 JPEG-файлами.
3
Подготовить тексты карточек  ~2 Ч
AI генерирует батчем: название (артикул + тип + серия + цвет), описание (2–3 предложения), характеристики (5–7 позиций), теги. На основе PDF-листовок и структуры из Excel.
4
Загрузить 204 карточки в каталог сайта  ~30 МИН
Через API сайта: создать карточку, загрузить фото, привязать к разделу Gaggenau. Батчевая загрузка. После — ручная проверка выборки (5–10 карточек).
