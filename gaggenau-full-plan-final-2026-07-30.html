Раздел 6
Сроки
Сколько времени займёт оформление всего раздела
После согласования формата карточки (этот документ) — запускаем автоматически. Ручное участие минимально.
День 1 · Согласование формата ½ дня
Поставщик подтверждает формат карточки (этот документ). Уточняем открытые вопросы (цены, фото, наличие). Запускаем следующие шаги.
День 1–2 · Сбор фото-библиотеки ~17 мин машинного времени
Скрипт проходит по всем 204 артикулам: скачивает PDF-листовку → извлекает фото (1195×1200 px) → сохраняет JPEG. Параллельно извлекаются характеристики. Для артикулов без листовки (~20%) — лайфстайл-фото из брошюры + запрос поставщику.
День 2 · Генерация описаний ~2 часа
AI батчем формирует для каждого артикула: краткое описание (2–3 предложения), теги-функции, перевод 10–12 технических характеристик. Источник — данные из PDF-листовок.
День 2–3 · Загрузка карточек на сайт ~30 мин
Батчевая загрузка через API сайта: создать карточку → загрузить фото → привязать к категории. 204 карточки загружаются в несколько проходов. Параллельно снимаются с публикации 27 старых моделей.
День 3 · Ручная проверка выборки 1–2 часа
Проверка 10–15 карточек разных категорий: фото, характеристики, описание, схема встраивания, кнопка КП. Правки при необходимости. Публикация раздела.
Итого: 3 рабочих дня после согласования РЕЗУЛЬТАТ
204 карточки опубликованы · 27 старых моделей сняты · аксессуары помечены «по запросу» · раздел Gaggenau готов к приёму трафика.
⏱ Что влияет на сроки
Срок 3 дня — при условии что: (1) формат карточки согласован, (2) есть ответы на вопросы из Раздела 7, (3) фото доступны из PDF-листовок. Если поставщик предоставит официальные фото пакетом — перезаливаем за 1 час.
Раздел 7
Вопросы к ООО «Гаггенау.Маркет»
Что ждём от поставщика для старта
1
Подтвердите формат карточки товара
Согласен ли поставщик с форматом, показанным в этом документе? Есть ли правки по полям, описанию, порядку характеристик? После «ок» — запускаем заливку всех 204 карточек по этому шаблону.
2
Цены: публикуем РРЦ или «по запросу»?
Если публикуем РРЦ — нужен прайс-лист с ценами на все 204 артикула Этапа А. Если «по запросу» — никаких дополнительных данных не нужно, запускаем сразу.
3
Можем ли использовать фото из PDF-листовок BSH Group?
Мы извлекаем фото товаров из официальных листовок Gaggenau (страница 1). Это официальные материалы бренда. Подтвердите, что можем их использовать на сайте homeproject.online без дополнительных разрешений.
4
Для ~20% артикулов листовок нет — как получить фото?
По некоторым позициям (часть вытяжек, грили, стиральные машины серии 200) публичной PDF-листовки нет. Есть ли у поставщика пакет официальных фото для этих моделей? Или предоставьте ссылки на листовки.
5
Уточните список старых моделей к снятию по всем категориям
В письме от 29.07 указаны модели для снятия по теплотехнике (духовки, пар, микроволновые, кофемашины, посудомоечные). Нужна аналогичная информация по: варочным панелям, холодильникам, вытяжкам, морозильникам, винным шкафам. Какие из них уже не актуальны?
6
Когда планируем запуск Этапа Б (аксессуары)?
233 позиции аксессуаров включены в прайс. Предлагаем заняться ими после запуска основного каталога (Этап А). Подтвердите, что это устраивает. Если есть приоритетные аксессуары (топ-продаж) — можем начать с них.
