3
Структура карточки товара
Предложение — на основе анализа PDF GO250100 / GO250130
PDF-документация Gaggenau содержит исчерпывающие данные. Для карточек на сайте предлагаем взять наиболее релевантную для покупателя часть, исключив технические разделы, предназначенные для специалистов по монтажу.
Оставить на карточке
  • ✓ 4–5 маркетинговых тезисов (перевод с немецкого)
  • ✓ Технические характеристики: объём, мощность, режимы, класс энергоэффективности
  • ✓ Аксессуары в комплекте с описанием
  • ✓ Опциональные аксессуары с артикулами
  • ✓ Схемы встраивания (монтажные чертежи как изображения)
  • ✓ Монтажные данные (зазоры, выступ фронта, требования к мебели)
  • ✓ Подключение к приложению (Home Connect)
Убрать / вынести отдельно
  • ✗ Руководство пользователя — ссылка на PDF Gaggenau
  • ✗ EU-регуляторика и маркировки
  • ✗ Open Source лицензии прошивки
  • ✗ Детальная инструкция по монтажу (26 глав)
  • ✗ Технический чертёж в векторном виде (заменяем JPEG)
