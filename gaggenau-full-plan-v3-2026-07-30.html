Раздел 3
Формат карточки товара
Структура и поля
Единый формат для всех 204 карточек. Примеры в следующем разделе.
// Заголовок карточки
Название (H1): <Артикул> <Тип> Gaggenau <Серия> — пример: GO250100 Духовой шкаф Gaggenau серия Minimalistic
URL: /gaggenau/<артикул-строчными> — пример: /gaggenau/go250100

// Основные поля
Изображение: официальное фото товара (из PDF-листовки), 1195×1200 px
Цена: по запросу (или РРЦ при наличии прайса от поставщика)
Наличие: «По запросу» (единый статус для всех Gaggenau)
Серия: Minimalistic / Expressive / серия 200 / серия 400
Цвет: антрацит / серебристый / нержавеющая сталь (по суффиксу артикула)

// Технические характеристики (5-7 позиций)
Ширина × высота: 60×60 / 76×60 / 45×60 и т.д.
Объём / мощность / функции — из PDF-листовки

// Теги
Теги: функциональные особенности (Пиролиз, WiFi, TFT Touch, ...)

// CTA
Кнопка: «Запросить КП» → форма лида (email + телефон + имя)
Аксессуары: «Доступны по запросу» — пометка под ценой
Суффикс артикула → цвет
100 = антрацит · 130 = серебристый
Кодировка Gaggenau: последние 2-3 цифры артикула содержат цвет
Определение ширины
220/240/250/260 = 60 см · 221/241 = 76 см
Второй блок цифр = кодировка размера и серии
Наименование
GO250100 Духовой шкаф Gaggenau серия Minimalistic
Структура: Артикул + Тип из Excel + Производитель + Серия
Цены
Публикуем РРЦ после получения прайса от поставщика
До получения прайса — «По запросу» на всех карточках

Раздел 5
Стратегия по фотографиям
Откуда берём фото для 204 карточек
📄
PDF-листовки от поставщика
Приоритет 1. У ООО «Гаггенау.Маркет» есть PDF-листовки по каждой позиции. Экспортируем изображения из PDF через инструменты (pdfimages / Adobe Acrobat). Размер — 1195×1200 px или больше. Формат — JPEG / WebP.

Покрытие: ~80% позиций Этапа А имеют PDF-листовку с официальным фото.
🌐
Официальный сайт Gaggenau
Приоритет 2. gaggenau.com → страница конкретной модели → скачать изображение продукта (правка «Сохранить изображение»). Официальные фото — белый фон, без водяного знака, используются дистрибуторами по всему миру.

Покрытие: 100% актуальных моделей Minimalistic / Expressive присутствуют на сайте.
🏠
Lifestyle-изображения
Приоритет 3. Для кухонных подборок и обложек коллекций — интерьерные фото из пресс-кита Gaggenau. Запрашиваем у поставщика или берём с официального пресс-портала (press.gaggenau.com).

Покрытие: нужны для главной страницы бренда и страниц категорий.
⚙️
Генерация заглушек
Приоритет 4. Для артикулов, по которым нет фото на старте — автоматическая заглушка с логотипом Gaggenau, артикулом и названием категории. SVG-шаблон, генерируется скриптом по списку артикулов.

Использование: временно, заменяем по мере получения официальных фото.
Запрос к поставщику
Просим ООО «Гаггенау.Маркет» предоставить: (1) медиа-кит с фото всех 204 позиций Этапа А; (2) доступ к пресс-порталу или ссылку на FTP с официальными изображениями; (3) подтверждение разрешения использовать фотографии на сайте дистрибутора.

Раздел 7
Агентская схема сотрудничества
Модель передачи лидов и агентского вознаграждения
Home Project выступает агентом ООО «Гаггенау.Маркет»: привлекает клиентов через сайт и CRM, квалифицирует лиды и передаёт поставщику для закрытия сделки. Продажа — через поставщика, оплата — на счёт поставщика.

Управление и контроль:
📊
CRM-трекинг
Каждый лид заводим в crm.db с тегом «gaggenau». Статусы: новый → квалифицирован → передан → в работе у поставщика → сделка закрыта.
📋
Еженедельный отчёт
Каждую пятницу — сводка по лидам: новые, переданные, статус у поставщика. Формат: Google Sheet или PDF, по договорённости с поставщиком.
💬
Канал связи
Оперативные лиды — через Telegram (ответ менеджера поставщика в течение 4 часов в рабочее время). Документы — email.
Конкурентное позиционирование
Home Project работает в сегменте «архитекторы и дизайнеры + высокобюджетные частные заказчики» в Москве. 14 001 контакт в CRM, из которых ~3 200 — архитекторы и дизайнеры. Это аудитория, которую Gaggenau.Маркет пока не охватывает напрямую через digital-каналы.
