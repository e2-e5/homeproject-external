Hubexo / NBS Source — не библиотека, а CRM

BCI Central (Австралия, 1998), куплена Byggfakta Group 2021, с 2024 = Hubexo. Видно кто скачал, какое бюро, какой проект. Можно связаться до тендера. Win rate 70–85%.

BIMobject — единственный с API

Полный REST API, OAuth2. Загрузка .rfa / IFC / DWG, параметры, аналитика скачиваний. Документация: github.com/bimobject/api-documentation

Главный вывод
.rfa моделирование — неизбежно, требует BIM-специалиста. Заливка данных (названия, параметры, описания, фото) — полностью автоматизируемо. Именно здесь AI-агент даёт 97% экономии.

Три варианта создания .rfa-файлов

BIMLIB Omega

BIMLIB делает .rfa сам (включено в тариф 585K руб/год). Срок: 6–10 нед. на 200 серий. Лучший вход для Фазы 1.

Dynamo batch-скрипт

Пишется 1 раз: Excel → 200 .rfa пакетом. Разработка: 1–2 нед. Dynamo-разработчика. Нужен Revit-ресурс.

Аутсорс BIM-моделлеру

$30–80 / семейство. 200 серий × $50 = ~$10 000. Срок: 6–10 нед. параллельно. Нужен для BIMobject (Фаза 2).

Раздел 07
AI-ассистенты + MCP-протокол · рекомендация
AI-оптимизация BIM-канала
Чтобы управлять BIM-каналом без раздутого штата, рекомендуем внедрить связку: языковая AI-модель + MCP-протокол. Это позволяет AI-ассистенту подключаться к любым внешним API как к инструментам и выполнять цепочки задач без участия человека.
Что такое MCP-протокол
MCP (Model Context Protocol) — открытый стандарт Anthropic (2024). AI-ассистент подключается к внешним системам: BIMobject API, CRM, email-рассылки, аналитика скачиваний. Агент сам выполняет цепочку: читает файл → вызывает API → получает результат → сообщает итог. Человек ставит цель, агент исполняет.

Как AI-агент ведёт BIM-канал — 6 шагов

1
Новый прайс от поставщика → разбор и подготовка контента

AI парсит Excel: 200 коллекций, 1 240 параметров. Генерирует описания RU/EN через языковую модель.

Вручную: 2–3 часа
AI-агент: ~8 минут
2
Загрузка 200 коллекций в BIMobject через API

AI создаёт карточки, прикрепляет .rfa-файлы, загружает фото, записывает все параметры. При изменении прайса — обновляет только изменившееся.

Вручную: 100–150 часов
AI-агент: ~30 минут
3
Мониторинг скачиваний — автоматический поллинг каждые 4 часа

BIMobject Analytics API отдаёт: страна, компания, дата, коллекция. Без AI менеджер узнаёт о скачивании случайно, заходя в кабинет раз в неделю.

Без AI: 3–7 дней задержки
AI-агент: менее 4 часов
4
Детекция лида: кто скачал → CRM + уведомление менеджера

AI сверяет скачивание с базой контактов. Создаёт лид. Отправляет уведомление менеджеру: «Бюро Citymaker (Москва) скачало 7 коллекций Terra. Контакт: arch@citymaker.ru».

Без AI: никогда / случайно
AI-агент: автоматически <1 мин
5
Автоматический аутрич — персонализированное письмо по событию

AI запускает рассылку по сегменту архитекторов с акцентом на популярные этой неделей коллекции. Тема письма адаптируется под тренд скачиваний.

Вручную: 1–2 недели
AI-агент: 2–4 часа
6
Синхронизация цен при смене прайса — сайт и BIMobject одновременно

Один Excel-файл → AI обновляет и интернет-магазин, и BIMobject-карточки без ручной работы.

Вручную: 3–5 дней
AI-агент: ~0 задержки
Ключевой инсайт
BIM-канал без мониторинга — пассивная библиотека: загрузили и ждём. С AI-агентом — активная воронка в реальном времени: каждое скачивание = детектированный лид за 4 часа → аутрич за 2 часа после. Это принципиально меняет конверсию канала.

Раздел 10
Выводы · решение
Ключевые выводы

Пять причин действовать прямо сейчас

  • Ниша свободна — и ненадолго. Ни один дистрибьютор плитки не занял BIM-площадки ни в России, ни в мире. Первый игрок получает 12–18 месяцев без конкуренции.
  • Spec-in = другая экономика. Win rate 70–85% против 15–25% в тендере. 4–5 сделок окупают весь год работы.
