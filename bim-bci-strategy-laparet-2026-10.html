BIMLIB БЕТА — точка входа

160 000 руб/год. 20 .rfa-объектов включены (пакет Omega). Прямой выход на 166 000 пользователей-проектировщиков и автоматическое попадание в ГИСП.

Тарифная лестница

БЕТА → ГАММА (285K, до 100 объектов) → ДЕЛЬТА (585K, неограниченно). Рост по мере накопления данных о ROI.

Принудительный рост спроса

БИМ/ТИМ обязателен по закону — не тренд, а регуляторное требование. Новые проекты = новые пользователи BIM-библиотек каждый год.

Hubexo / NBS Source — не библиотека, а CRM

Hubexo (бывш. BCI Central, Австралия, 1998, куплена Byggfakta Group 2021) — это активная воронка: видно, кто скачал, какое бюро, какой проект. Именно здесь достигается win rate 70–85%. Контакт с архитектором — до начала тендера.

BIMobject — единственный с API

Полный REST API, OAuth2. Загрузка .rfa/.ifc/DWG, свойства продуктов, аналитика скачиваний — всё через программный интерфейс. Документация: github.com/bimobject/api-documentation. Это единственная мировая платформа, где весь цикл автоматизируем.

Санкционный вопрос: решаемо Для всех глобальных платформ нужно юрлицо ОАЭ (Ajman/DMCC, ~$3–5K, 2–4 нед.) или Армения. Это стандартное решение, не барьер для старта.

AI-ассистенты + MCP-протокол · рекомендация РАЗДЕЛ 08

AI-оптимизация: рекомендация для Баусервис

Чтобы управлять BIM-каналом без раздутого штата, рекомендуем внедрить связку: языковая AI-модель + MCP-протокол (Model Context Protocol, открытый стандарт Anthropic, 2024). Это позволяет AI-ассистенту подключаться к любым внешним API как к инструментам.

Что такое MCP (Model Context Protocol) Открытый стандарт, при котором AI-ассистент получает доступ к внешним системам — BIMobject API, CRM, email-рассылкам, аналитике — через стандартный протокол. Агент сам выполняет цепочку задач: читает файл → вызывает API → получает результат → сообщает итог. Человек ставит цель, агент исполняет.

Итоги РАЗДЕЛ 11

Выводы

1
Ниша свободна — и ненадолго

Ни один дистрибьютор плитки не занял BIM-площадки ни в России, ни в мире. Первый игрок получает 12–18 месяцев без конкуренции и устойчивый «эффект привычки» у архитекторов.

2
Spec-in = другая экономика

Win rate 70–85% против 15–25% в тендере. 4–5 сделок окупают год работы по всем статьям. BIM-присутствие — это не маркетинг, это смена позиции в цепочке принятия решений.

3
AI + MCP — не опция, а конкурентное преимущество

Без автоматизации BIM-канал не масштабируется: 200 коллекций вручную = 150 часов. С AI-агентом — 30 минут. Это разница между нишевым экспериментом и работающим каналом продаж.

4
Международный рынок — стратегический актив

Баусервис как spec-in агент для Морби на Hubexo — уникальная позиция, которой нет ни у кого. 800+ заводов, $2,2B экспорта, ноль представительства на мировых BIM-платформах.

5
Экономика сходится

Инвестиции год 1: ~1M руб (Россия, без ОАЭ). 3–5 сделок = полная окупаемость. AI-экономия трудозатрат: ~1M руб/год дополнительно. ROI без единой сделки уже положительный.
