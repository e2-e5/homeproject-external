01
Концепция
Что такое BIM-канал и механика spec-in
BIM-канал — цифровая библиотека, где производитель публикует «BIM-объекты» своих коллекций. Архитектор скачивает объект и вставляет плитку в модель здания. Продукт, зафиксированный в спецификации до тендера, почти не меняется при закупке — это механика spec-in.

Обычные продажи сегодня

  • Узнаём о проекте на стадии тендера
  • Конкурируем с 5-15 аналогами по цене
  • Win rate: 15-25%
  • Маржа давится ценовой войной

Spec-in через BIM-канал

  • Архитектор сам выбирает LAPARET в BIM
  • Продукт в спецификации до тендера
  • Win rate: 70-85%
  • Заменить сложно — маржа сохранена

Hubexo vs BIMLIB — ключевое отличие
BIMLIB = пассивная библиотека. Hubexo = активная воронка продаж: конкретное бюро, проект, архитектор — до тендера. Это CRM по архитекторам в реальном времени.

05
AI-агенты · MCP-протокол
Что мы уже умеем и как это применить к BIM
MCP (Model Context Protocol, Anthropic) — стандарт, позволяющий AI-агенту вызывать внешние API как инструменты. Баусервис уже работает на этом стеке: агент управляет каталогом Medusa, отправляет рассылки через UniSender, публикует страницы. Следующий шаг — применить тот же подход к BIM-платформам.

Как Баусервис уже использует AI-агентов (MCP)

ЗадачаMCP-инструментЧто делает агентЭкономия
Каталог сайтаmedusa_create_product, medusa_update_contentСоздаёт карточки товаров, обновляет описания и цены по прайсу~80% времени
Email-рассылкиunisender_send_email, crm_segmentСегментирует базу, создаёт шаблон, отправляет кампанию~70% времени
Внешние страницыpublish_external_pageГенерирует HTML-презентации, КП, лендинги — этот документ~90% времени
Telegram/ВКонтактеtelegram_post, vk_postПланирует и публикует посты по контент-плану~75% времени

Из операционного опыта Баусервис, сентябрь 2026. Инфраструктура: Claude + MCP + собственный сервер агентов.

Принцип — тот же, инструмент — другой
Для Medusa у нас есть MCP-сервер с функцией medusa_create_product. Для BIMobject нужно создать аналогичный MCP-сервер с функцией bimobject_create_product. Логика идентична: агент читает Excel-каталог, вызывает API, получает результат. Разница только в том, что BIMobject API уже задокументирован — нам остаётся написать обёртку.

Вывод: BIMobject — единственная цель для MCP-автоматизации
Из всех мировых BIM-платформ только BIMobject имеет публичный documented REST API. Ни BIMLIB, ни Hubexo/NBS Source, ни Archiproducts не предоставляют доступа для автоматической загрузки. Вложения в MCP-коннектор оправданы только для BIMobject.
06
BIMobject Publish API · верифицировано
Детальная механика: как работает API и что автоматизирует агент
BIMobject Publish API — полноценный REST API с OAuth2 и Swagger-документацией. Покрывает полный жизненный цикл продукта: создание, загрузку файлов (включая .rfa), свойства, изображения, версии. Всё, что делается вручную в web-кабинете — делает агент через API.

Подтверждённые эндпоинты BIMobject Publish API

ОперацияМетод + URLЧто делает
Загрузить файлPOST /v1/uploadsЗагружает blob (файл любого типа), возвращает одноразовый blobId
Создать продуктPOST /v1/brands/{brandId}/productsСоздаёт карточку продукта в каталоге бренда
Обновить продуктPUT /v1/brands/{brandId}/products/{id}Обновляет метаданные (название, описание, категория)
Прикрепить файлPOST /v1/brands/{brandId}/products/{id}/filesПрикрепляет blobId к продукту (.rfa, IFC, DWG — любые форматы)
Добавить изображениеPOST /v1/brands/{brandId}/products/{id}/imagesПрикрепляет blob с фото (render, текстура)
Задать свойстваPUT /v2/brands/{brandId}/products/{id}/propertyvaluesЗаписывает тех. параметры: размеры, R-value, поверхность, морозостойкость

Список форматовGET /v1/masterdata/products/filetypesКакие форматы принимает платформа (.rfa, .gsm, IFC, .skp, DWG и др.)

Источник: publish-publicapi.bimobject.com/swagger/index.html + github.com/bimobject/api-documentation (верифицировано)

# Пример: создание продукта через BIMobject Publish API (Python) import httpx # 1. Получить токен (OAuth2 client_credentials) token_resp = httpx.post("https://auth.bimobject.com/connect/token", data={ "grant_type": "client_credentials", "client_id": CLIENT_ID, "client_secret": CLIENT_SECRET, "scope": "admin.product.write" }) token = token_resp.json()["access_token"] headers = {"Authorization": f"Bearer {token}"} # 2. Загрузить .rfa файл — получить blobId with open("laparet_terra_600x600.rfa", "rb") as f: blob = httpx.post("https://publish-publicapi.bimobject.com/v1/uploads", headers=headers, files={"file": f}) blob_id = blob.json()["blobId"] # одноразовый ID # 3. Создать продукт product = httpx.post(f"https://publish-publicapi.bimobject.com/v1/brands/{BRAND_ID}/products", headers=headers, json={"name": "Terra Collection 600x600", "categoryId": "floor-tiles"}) product_id = product.json()["id"] # 4. Прикрепить .rfa → 5. Задать свойства из Excel httpx.post(f".../products/{product_id}/files", headers=headers, json={"blobId": blob_id, "fileTypeCode": "RFA", "revitVersion": "2024"}) httpx.put(f".../products/{product_id}/propertyvalues", headers=headers, json=[{"propertyId": "dimensions", "value": "600x600x10mm"}, {"propertyId": "surface", "value": "Matt"}, {"propertyId": "frost_resistant", "value": True}]) # Итого: ~8 секунд машинного времени на 1 продукт
Требование: ручной онбординг в BIMobject (1 раз)
API-доступ не самостоятельный. (1) Регистрация на developer.bimobject.com, (2) brand-аккаунт через менеджера BIMobject, (3) получить client_id/client_secret. Срок: 1-2 недели. После — автоматизация без ограничений. Важно: blobId одноразовый — нельзя один .rfa прикрепить к 200 карточкам без перезагрузки файла для каждой.

Автоматизируется агентом (AI + API)

  • Создание карточек из Excel
  • Загрузка .rfa файлов (если файл готов)
  • Запись всех тех. свойств из прайса
  • Загрузка фотографий и текстур (PNG/JPG)
  • Обновление цен и характеристик
  • Управление версиями (.rfa под Revit 2023-2025)
  • Генерация описаний через LLM из тех. данных

Остаётся ручным / требует человека

  • Создание .rfa файла — Dynamo-скрипт или BIM-моделлер (главный bottleneck)
  • Первичный онбординг в BIMobject (1 раз)
  • QA каждого 10-го объекта
  • Тех. паспорта от поставщика
  • CE/EPD сертификаты (от завода)
  • Одобрение публикации в BIMobject (модерация)

Следующие шаги — октябрь 2026

Октябрь 2026 — что делаем прямо сейчас

  • 1. BIMLIB БЕТА (160K руб). Договор, топ-20 коллекций, ответственный менеджер. Нед. 1-7 окт.
  • 2. .rfa-семейства. BIMLIB Omega (включено) или нанять BIM-моделлера. Техдокументация от поставщика.
  • 3. Регистрация на developer.bimobject.com — параллельно, ждать 1-2 нед. Получить client_id/secret. Начало разработки MCP-коннектора (2-4 нед. backend).
  • 4. Запрос в NBS Source: salessupport@theNBS.com — цены и условия для иностранного поставщика через ОАЭ.
  • 5. Запрос в Renga BIM-каталоги: bimcatalogs.rengabim.com — условия входа.
  • 6. Первый контакт Nitco / Simpolo (Морби): письмо об интересе к эксклюзивному spec-in агентству.
  • 7. Юрлицо ОАЭ: запросить Virtuzone / Ajman Free Zone — стоимость и срок.
