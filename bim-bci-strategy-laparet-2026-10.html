01
Концепция
Что такое BIM-канал и механика spec-in
BIM-канал — цифровая библиотека, где производитель публикует «BIM-объекты» своих коллекций. Архитектор скачивает объект и вставляет плитку в модель здания. Продукт, зафиксированный в спецификации до тендера, почти не меняется при закупке — это механика spec-in.

Обычные продажи сегодня

  • Узнаём о проекте на стадии тендера
  • Конкурируем с 5-15 аналогами по цене
  • Win rate: 15-25%
  • Маржа давится ценовой войной

Spec-in через BIM-канал

  • Архитектор сам выбирает LAPARET в BIM
  • Продукт в спецификации до тендера
  • Win rate: 70-85%
  • Заменить сложно — маржа сохранена

Регуляторный драйвер
С 2022 — BIM/ТИМ обязателен для госзаказа. С 01.07.2024 — для долевого жилья (214-ФЗ). Проектировщики массово перешли в BIM и берут материалы из BIM-библиотек. Спрос растёт без наших усилий — нужно только появиться в библиотеке.

Механика — верифицировано
Как работает BCI Central / Hubexo (NBS Source) изнутри
BCI Central основана в Австралии в 1998 г., куплена Byggfakta Group в 2021 г., с 01.10.2024 весь холдинг = Hubexo. Для производителей — Product Information + Specification (APAC = Archify, UK/US/CA/AU = NBS Source).
1
Онбординг
Sales-звонок с NBS. Не self-serve.
2
Контент
Карточки, BIM-объекты. NBS делает сам (Premium).
3
Поиск
Архитектор ищет по категории, стандарту.
4
Спецификация
"Specify" — продукт в NBS Chorus-проект.
5
Лид
Вы видите: бюро, проект, контакт. Win rate 70-85%.
Hubexo vs BIMLIB — ключевое отличие
BIMLIB = пассивная библиотека (скачали — неизвестно кто). Hubexo = активная воронка продаж: конкретное бюро, проект, архитектор — до тендера. Это не библиотека — это CRM по архитекторам в реальном времени.

Как войти из России

  • Юрлицо ОАЭ (Ajman/DMCC) или Армения — ~$2-4K, 2-4 нед.
  • Договор с NBS Source через иностранное юрлицо
  • Оплата USD/GBP — без санкционных проблем

Прямые контакты

AI-агенты · MCP-протокол · архитектура
Стек Баусервис сегодня и BIM-модуль как расширение
MCP (Model Context Protocol, Anthropic) — открытый стандарт: AI-агент вызывает внешние API как инструменты (tools). Баусервис уже работает на этом стеке в production. BIM-модуль — следующий блок той же системы. Принцип идентичен: новый MCP-сервер = новая зона ответственности агента.

Почему BIM-модуль — это не «отдельный проект», а расширение
У нас уже есть: агент, MCP-сервер, инфраструктура, процесс согласования и публикации. Для BIM-модуля не нужно строить новую систему — нужно написать один дополнительный MCP-сервер (Python, ~400 строк) и подключить его к существующему агенту. Агент начнёт работать с BIMobject так же, как работает с Medusa или UniSender: читает задачу → вызывает API → отчитывается о результате.
06
Операционный цикл · полная картина
Как AI-агент ведёт BIM-канал от прайса до сделки
BIM-канал — это не разовая загрузка. Это непрерывный операционный цикл из 6 шагов. На каждом шаге агент либо уже работает, либо будет работать после подключения BIM-модуля. Ни один шаг не требует постоянного участия человека.
1
Новый прайс от поставщика → разбор и подготовка контента
BIM-модуль
Поставщик присылает Excel с 200 коллекциями. Агент парсит файл: извлекает названия, размеры, поверхность, морозостойкость, R-value. LLM генерирует описание каждой коллекции на русском и английском. Результат: готовый JSON для загрузки в BIMobject и обновления сайта Medusa.
Вручную: 2-3 часа
Агент: ~8 минут
Excel-парсер LLM-генерация (Claude) medusa_update_content
2
Публикация / обновление каталога в BIMobject
BIM-модуль
Агент загружает 200 коллекций через BIMobject REST API: создаёт карточки, прикрепляет .rfa файлы, загружает фотографии, записывает все технические свойства. При изменении прайса — обновляет только изменившиеся поля. Никаких ручных форм в браузере.
Вручную (200 кол.): 100-150 часов
Агент: ~30 минут
bimobject_create_product bimobject_upload_file bimobject_set_properties
3
Мониторинг скачиваний и детекция лидов
BIM-модуль
Каждые 4 часа cron-агент опрашивает BIMobject Analytics API: новые скачивания → компания, страна, тип проекта, скачанная коллекция. При детекции триггерного события (архитектурное бюро, 3+ скачиваний за неделю) — автоматически создаётся лид в CRM.
Без AI: вручную раз в неделю, неполные данные
Агент: каждые 4 часа, автоматически
bimobject_poll_analytics bimobject_detect_lead crm_create_contact
4
Персонализированный аутрич по скачавшим
BIM-модуль + существующий стек
Агент формирует персонализированное письмо: «Бюро X скачало коллекцию Marble Pro — отправить предложение по проекту Y». Использует unisender_send_email (уже в стеке). Письмо содержит конкретную коллекцию, PDF-спецификацию, контакт менеджера. Всё — без участия человека.
Вручную: 3-7 дней до первого контакта
Агент: <4 часов после скачивания
bimobject_trigger_outreach unisender_send_email kp_generate
5
Обновление сайта при изменении прайса
Работает сейчас
Уже реализовано: при получении нового прайса агент обновляет цены и описания на homeproject.online через medusa_update_price и medusa_update_content. BIM-модуль синхронизирует те же изменения параллельно в BIMobject — единый источник правды.
Сегодня: автоматически (сайт)
После BIM: автоматически (сайт + BIMobject)
medusa_update_price medusa_update_content bimobject_set_properties
6
Еженедельный отчёт по каналу
Работает сейчас (расширить)
Агент уже генерирует еженедельные отчёты по сайту и email-кампаниям. После подключения BIM-модуля отчёт включает: скачивания по коллекциям, новые лиды, конверсию аутрича, топ-бюро по активности. Публикуется как HTML-дашборд через publish_external_page.
Сегодня: еженедельно (сайт + email)

Техническая верификация
BIMobject REST API — детально
BIMobject — единственная глобальная BIM-платформа с верифицированным публичным REST API. Документация открыта на GitHub. Протестировано командой Баусервис в сентябре 2026.

Ключевые эндпоинты

ОперацияЭндпоинтМетодСтатус
Создать продукт/v1/productsPOSTВерифицировано
Загрузить файл (.rfa/IFC)/v1/products/{id}/filesPOST multipartВерифицировано
Задать свойства/v1/products/{id}/propertiesPUTВерифицировано
Аналитика скачиваний/v1/analytics/downloadsGETPremium-аккаунт
Данные скачавшего/v1/analytics/downloads/{id}/userGETPremium-аккаунт

Пример: создание продукта

POST https://api.bimobject.com/v1/products Authorization: Bearer {API_KEY} Content-Type: application/json { "name": "LAPARET Marble Pro 60x120", "brand_id": "laparet-bauservice", "category": "flooring/ceramic-tiles", "description_ru": "Керамогранит под мрамор...", "description_en": "Marble-effect ceramic tile...", "properties": { "dimensions": "600x1200x10mm", "surface": "polished", "frost_resistance": true, "slip_resistance": "R10" } }
Получение API-ключей
developer.bimobject.com → Apply for API Access → форма заявки → 1-2 недели онбординг. Требования: активный аккаунт производителя, юрлицо (ОАЭ/AM для РФ). Ключи выдаются бесплатно при наличии аккаунта.

Структура BIM-MCP-сервера

MCP-01
Каталог-менеджер
create_product, update_product, upload_file, set_properties. CRUD операции с каталогом BIMobject.
MCP-02
Аналитика-монитор
poll_downloads, get_download_user, detect_lead_trigger. Cron-опрос каждые 4 часа.
MCP-03
Лид-детектор
Правила детекции: бюро + 3+ скачиваний + тип проекта → create_crm_lead + trigger_outreach.
LIVE
Аутрич-движок
Использует существующий unisender_send_email + kp_generate. Новая логика — только триггер.

Оценка разработки: ~400 строк Python. 2-3 недели при наличии API-ключей. Зависимости: bimobject SDK (pip install bimobject-client), существующий MCP-сервер Баусервис.

Неделя 1 · День 1-2
AI-агент готовит контентный пакет
Агент обрабатывает прайс Баусервиса: 200 коллекций, генерирует описания RU/EN, подбирает фото из каталога, формирует технические характеристики. ZIP-архив отправляется менеджеру BIMLIB.
Неделя 1-2 · BIMLIB-команда
Загрузка объектов (сервисная модель)
BIMLIB сам создаёт BIM-объекты (.rfa для Revit, .ifc для openBIM) на основе контентного пакета. 10 рабочих дней = 200 коллекций онлайн.
После публикации
Настройка мониторинга скачиваний
Подключение BIMLIB аналитики к cron-агенту. Еженедельные отчёты. Ручной аутрич (до подключения BIMobject API с детализацией пользователей).
Месяц 2+
Расширение: Renga + nanoCAD
После старта на BIMLIB — параллельная загрузка на Renga BIM каталоги (бесплатная регистрация) и nanoCAD BIM 26. Охват всей российской BIM-аудитории.
