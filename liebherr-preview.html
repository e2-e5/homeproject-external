Технологии

Немецкие инновации для вашего дома

Четыре фирменные технологии Liebherr, которые задают стандарт в холодильной технике.

BioFresh
Поддерживает оптимальный микроклимат для разных типов продуктов. Фрукты, овощи, рыба и мясо хранятся свежими до 3 раз дольше.
DuoCooling
Два независимых контура охлаждения для холодильника и морозильника. Запахи не смешиваются, влажность поддерживается оптимально.
NoFrost
Автоматическая разморозка — никакого инея и наледи. Равномерное охлаждение по всему объёму. Забудьте о размораживании навсегда.
SmartSteel
Специальное покрытие нержавеющей стали — устойчиво к отпечаткам пальцев. Поверхность всегда выглядит безупречно без лишних усилий.
Серия IRB Compact

Встроится в любую кухню. Буквально.

Серия Compact — встраиваемые холодильники Liebherr для ниш от 87 до 178 см. Идеальное решение для проектов, где нужна гибкость: острова, пеналы, нестандартные расстановки.

  • 5 высот ниши: 87 / 121 / 139 / 177 / 194 см Подходит для любого архитектурного решения без компромиссов.
  • Шарниры SoftClose и светодиодное освещение Мягкое закрывание и равномерная подсветка всего внутреннего пространства.
  • Плоский шарнир для фасадов под мебель Дверь полностью скрывается за кухонным фасадом — безупречная эстетика.
  • Гарантия 5 лет на компрессор Немецкое качество подкреплено официальной гарантией производителя.
