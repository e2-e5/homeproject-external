  • 📍 МСК-агломерация — крупнейший единый рынок РФ; бизнес-класс (28%) — главный потребитель импортной плитки €8–20/м²
  • 💰 Инфраструктурный бум — промышленные, коммерческие и транспортные объекты дают дополнительный спрос на технический керамогранит
  • 📈 CAGR +3–5% — рост строительства РФ в 2024–2026 за счёт бюджетного финансирования инфраструктуры и льготной ипотеки

РФ производит 250 млн м² (75% самообеспеченность). Импорт — преимущественно средний и люкс. Laparet / KM Group доминируют в эконом-среднем. Premium-сегмент зависит от импорта.
🚀
Растущие рынки
ОАЭ, Саудовская Аравия — активная застройка, 35%+ premium жилья, дефицит произв. → высокий импорт. Индия — быстрый рост premium с 17% до 20%+.
📉
Риски рынка
Глобальное производство плитки упало на −6.2% — 3-й год снижения. Китай: переизбыток мощностей (48% утилизация). Вьетнам агрессивно занимает долю Китая по экспорту.
🏠
Классы жилья → плитка
Luxury/Premium жильё (США 41%, ОАЭ 35%, РФ Бизнес+ 28%) — прямой драйвер спроса на итальянский керамогранит €15–35/м². Рост премиального стр-ва = рост import premium.
📚 Источники и методология
Ceramic World Web (Faenza Editrice)
Глобальная статистика производства и экспорта плитки. Ежегодный отчёт World Production and Consumption of Ceramic Tiles 2024. Основной источник по объёмам.
TECNAEXPO — Ceramic Tiles Reports
Торговые потоки, экспортные цены по странам-производителям. Данные по Италии, Испании, Турции, Вьетнаму (2023–2024).
Statista — Global Ceramics Industry
Рыночные доли, сегментация по типам продукции, импорт США ($2.42 млрд), данные по ценовым диапазонам. Агрегированные данные 2024.
AECOM Global Construction Outlook 2024
Объёмы строительного рынка по странам (млрд USD). Прогнозы роста, региональная сегментация. Данные по США, Китаю, Европе, APAC.
ResearchAndMarkets — Ceramic Tile Market
Рыночные исследования по сегментам и регионам. Классы жилья → потребление плитки. CAGR прогнозы 2024–2029.
IndexBox — Trade Analytics
Детализация торговых потоков: США ← Италия/Испания/Мексика. Ценовые данные по экспортным поставкам. Тренды 2022–2024.
Harvard JCHS (Joint Center for Housing Studies)
Сегментация строительства жилья США по классам (luxury 41.3%). Тренды 2023–2024.
Rosstat / ДОМ.РФ — данные по РФ
Производство плитки в РФ, сегментация новостроек МСК/СПБ по классам (Бизнес+ 28%, Комфорт 45%, Эконом 27%). Данные 2023–2024.
Kerama Marazzi IR / открытая отчётность
Данные по бренду Laparet: производственные мощности, дистрибуция, ценовой сегмент, позиция на рынке РФ. 2023–2024.
Методология: данные собраны из открытых отраслевых источников и агрегированы с применением ИИ-инструментов. Ряд данных (строительный рынок РФ, доли бренда Ceradin) — оценочные, требуют верификации у отраслевых партнёров. Торговые потоки в РФ приведены по последним доступным данным (2022–2024), часть маршрутов изменилась с 2022 г.
